## 3️⃣ Module quan trọng nhất: `orders/`

```text
orders/
├── api.py            # REST endpoints
├── models.py         # SQLAlchemy Order
├── schemas.py        # Request / Response
├── service.py        # Business logic
├── repository.py     # DB access
└── state_machine.py  # RULE CHUYỂN TRẠNG THÁI
```

### Trách nhiệm

* Create order
* Change state
* Validate transition

👉 **State machine nằm riêng** → ăn điểm rất mạnh

---

## 4️⃣ `inventory/` – nơi xử lý tranh chấp

```text
inventory/
├── service.py        # Reserve / release
├── repository.py     # DB inventory
└── redis_store.py    # Redis lock + TTL
```

### Nhiệm vụ

* Hold inventory
* TTL hết → auto release
* Redis lock vé cuối

👉 Booking + ecommerce đều dùng được

---

## 5️⃣ `payments/` – nơi dễ sai nhất

```text
payments/
├── api.py            # Initiate payment
├── service.py        # Payment logic
├── gateway.py        # Mock Stripe/PayPal
└── webhook.py        # Idempotent handler
```

### Bắt buộc có

* Idempotency
* Check order state
* Retry-safe

👉 Không làm đúng chỗ này = **fail system**

## 6️⃣ `reservations/` – timeout

```text
reservations/
├── service.py
└── timeout_worker.py
```

### Làm gì?

* Order pending quá lâu

👉 Đây chính là **Saga pattern nhẹ**
