# ROADMAP – TICKET BOOKING SYSTEM

**Stack:** Python + FastAPI + PostgreSQL + Redis

Mục tiêu:
Người dùng chọn ghế → hệ thống lock ghế → thanh toán giả lập → commit vé → auto rollback nếu timeout.

---

## Giai đoạn 1 — Thiết kế dữ liệu (1–2 ngày)

**Tables chính:**

```
users(id, name, email)

events(id, title, venue, datetime)

seats(id, event_id, seat_number, status)
status: available | locked | booked

orders(id, user_id, event_id, status, total_price)
status: pending | paid | cancelled | expired

order_items(id, order_id, seat_id)

payments(id, order_id, status)
```

**Redis:**

* Key: lock:seat:{seat_id} → TTL 5 phút

---

## Giai đoạn 2 — API cơ bản (3–4 ngày)

**Endpoints:**

* GET /events

* GET /events/{id}/seats

* POST /orders
  → tạo order pending

* POST /orders/{id}/lock
  → lock seats
  → set Redis TTL
  → update seat status = locked

* POST /orders/{id}/pay
  → giả lập thanh toán
  → commit transaction:

  * payment success
  * seat → booked
  * order → paid
  * remove Redis locks

---

## Giai đoạn 3 — Transaction logic (3–5 ngày)

Dùng **PostgreSQL transaction**:

```
BEGIN

check seat availability FOR UPDATE
insert order
update seats -> locked
create payment record

COMMIT
```

Nếu bất kỳ lỗi → ROLLBACK

---

## Giai đoạn 4 — Auto rollback khi hết hạn lock (2 ngày)

Worker background:

* Cron job mỗi phút:
* Quét Redis key hết TTL
* Với seat lock expired:

  * seat → available
  * order → expired
