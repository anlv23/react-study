# MODULE: Orders – Simple Pseudocode

Giả định:

* `db` = PostgreSQL
* `redis` = Redis
* TTL_LOCK = 300s

---

## 1) User chọn ghế → Lock ghế tạm

**POST /seats/{seat_id}/lock**

```pseudo
function lock_seat(user_id, seat_id):

    lock_key = "lock:seat:" + seat_id

    // Try Redis lock first
    success = redis.SET(lock_key, user_id, NX=true, EX=TTL_LOCK)

    if success == false:
        return error("Seat is being held by another user")

    // Update DB seat status
    seat = db.get_seat(seat_id)

    if seat.status != "available":
        redis.DEL(lock_key)
        return error("Seat not available")

    db.update_seat_status(seat_id, "locked")

    return success("Seat locked for 5 minutes")
```

---

## 2) Tạo order từ các ghế đã lock

**POST /orders**

```pseudo
function create_order(user_id, seat_ids):

    // Verify user owns all locks
    for seat_id in seat_ids:
        lock_owner = redis.GET("lock:seat:" + seat_id)
        if lock_owner != user_id:
            return error("Seat lock missing or expired")

    // Create order
    order_id = db.insert_order(user_id, status="pending")

    // Attach seats to order
    for seat_id in seat_ids:
        db.insert_order_item(order_id, seat_id)

    return {order_id, message:"Order created"}
```

---

## 3) Thanh toán → Commit vé

**POST /orders/{order_id}/pay**

```pseudo
function pay_order(user_id, order_id):

    order = db.get_order(order_id)

    if order.status != "pending":
        return error("Order not payable")

    seat_ids = db.get_order_seats(order_id)

    BEGIN TRANSACTION

    // Check locks still valid
    for seat_id in seat_ids:
        lock_owner = redis.GET("lock:seat:" + seat_id)
        if lock_owner != user_id:
            ROLLBACK
            return error("Seat lock expired")

    // Simulate payment success
    db.insert_payment(order_id, status="success")

    // Commit seats
    db.update_seats_status(seat_ids, "booked")

    // Update order
    db.update_order_status(order_id, "paid")

    COMMIT

    // Remove Redis locks
    for seat_id in seat_ids:
        redis.DEL("lock:seat:" + seat_id)

    return success("Payment success. Seats booked.")
```

---

## 4) Hết thời gian giữ ghế → Auto rollback

**Background Worker (chạy mỗi phút)**

```pseudo
function release_expired_locks():

    locked_seats = db.get_seats_by_status("locked")

    for seat in locked_seats:
        lock_key = "lock:seat:" + seat.id

        if redis.GET(lock_key) == null:
            // Lock expired → release seat
            db.update_seat_status(seat.id, "available")
```

(Đơn giản hóa: Order pending liên quan có thể set "expired" sau)

# Luồng tổng thể

```
User chọn ghế
    ↓
/seats/{id}/lock  → Redis giữ TTL
    ↓
/orders → tạo order pending
    ↓
/orders/{id}/pay → commit DB + xoá Redis
    ↓
Nếu không pay → Redis TTL hết → worker mở ghế
```
